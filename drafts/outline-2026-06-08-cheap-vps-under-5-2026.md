- 起价 1GB 套餐:$1.99/月,2GB 起跳,$10.98/年(年付约 $0.92/月)

### H2 #4 — Vultr:全球节点 + 小时计费,适合弹性场景
- 起价 $2.50/月(高频促销),1GB / 1 vCPU / 25GB NVMe / 1TB 流量

- 缺点:2024 年起价格小幅上调,2026 年入门档略高于 RackNerd
- 适合:全球化部署 / API 服务 / 短期爬虫任务

### H2 #5 — DigitalOcean:文档 + 生态最好的「开发者友好」VPS
- Basic Droplet $4/月,1GB / 1 vCPU / 25GB SSD / 1TB 流量
- 15 个机房(8 个国家),覆盖核心区域
- 强项:文档质量全网第一,App Platform / Kubernetes / Spaces 生态成熟
- 适合:开发团队 / 教育 / 需要文档支持的小团队
- 缺点:同价位下 RAM 比 Contabo / Hostwinds 少

### H2 #6 — Contabo:大内存 + 大硬盘的「德式性价比之王」
- Cloud VPS S 4.50 EUR/月(约 $4.85),4 vCPU / 8GB RAM / 50GB SSD / 32TB 流量

- 适合:预算敏感但需要大内存/大硬盘的用户

### H2 #7 — Hostwinds / Interserver:首单优惠 + 续费透明的代表

- Hostwinds 强项:自定义 ISO / Windows VPS 友好
- Interserver 强项:十年以上老牌,15 天退款保证
- 适合:长期合约 / 厌恶「续费陷阱」的用户

### H2 #8 — Hostinger / UpCloud / HostPapa:补充场景

### H2 #10 — FAQ(SGE 友好,5 问)
- **Q1:$1.99 的 RackNerd VPS 真的能跑生产吗?**
  A:可以。1GB RAM 对 WordPress / 小型 SaaS / 反向代理够用;2GB 起($10.98/年)更稳。不建议拿 $1.99 跑大型数据库。
- **Q2:Contabo 为什么便宜?有什么坑?**
  A:同价位下 RAM/硬盘是其它商家的 4-8 倍。代价是单核 CPU 性能一般,机房覆盖少于 Vultr。适合预算敏感 + 不追求单核性能的用户。
- **Q3:首月 $1 后续涨价的套路怎么避?**
  A:看商家是否提供「price lock」或「终身优惠」。RackNerd 终身价续费不涨;Interserver 提供 price lock;Vultr/DigitalOcean 按官网当前价续费,基本不主动涨。**避免**首单低于 $2、续费涨 3 倍以上的纯促销机型。
- **Q4:$5/月以下 VPS 适合跑 Docker / K3s 吗?**
  A:轻量 Docker Compose 可以(2GB+ RAM);K3s 单节点可以但不能跑生产集群。要做 K8s 生产环境,至少 4GB / $15-20/月起步。
- **Q5:买便宜的 VPS 怎么避免被商家跑路?**
  A:看商家运营年限(>5 年为佳)+ 用户基数(>10000 客户)+ 多机房冗余。白名单 14 家都满足。**永远跨厂商备份**——主站 + 备份用不同商家。
