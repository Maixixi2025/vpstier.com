## 7. Fact bundle — reusable, verified 2026-09-13

**ServerVerify (vendor-operated facts, from `/faq` + `/about`):**
- Free to use; register / submit benchmarks / leave reviews at no cost; can browse public content without an account.
- **Score** = composite of a **YABS (Yet-Another-Bench-Script)** run: **CPU** (Geekbench single + multi-core), **disk** (fio read/write across multiple block sizes), **network** (iperf3 send/receive to multiple global test servers). Categories normalised to a common scale, weighted, summed. **Not capped** — faster hardware scores higher, so cross-generation comparison stays meaningful.
- **A–F grades:** A = top-tier/among the fastest tested; B = strong, above market average; C = mid-range typical for standard hosting; D = below average (may indicate resource or configuration issues); F = substandard, below baseline.
- Incomplete runs render missing fields as **"N/A"** (e.g. user aborts, or the Geekbench CPU test fails to execute).
- **Value Index** = benchmark score ÷ monthly price → a "Value Score". **Only benchmarks carrying valid price data are included.**
- Providers can be added by users; **verified providers can claim profiles and respond publicly** to reviews/benchmark results.
- **Operated by WNY IT Services Inc.**, the same company as LowEndBox and LowEndTalk. Platform self-describes as "used by millions" (vendor claim — attribute or omit).
